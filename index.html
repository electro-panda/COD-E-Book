Unit 1: Combinational Circuits (Adders & Subtractors)

Combinational logic circuits compute outputs purely as a function of their instantaneous input values, without internal feedback or memory loops.

1. Half Adder

Adds two single binary digits ($A$ and $B$), outputting Sum ($S$) and Carry ($C$). The schematic below shows explicit binary data values ($A=1, B=1$) propagating through the XOR and AND logic gates to yield $S=0$ and $C=1$.

2. Full Adder

Computes arithmetic sum of three 1-bit inputs: $A$, $B$, and input carry $C_{in}$.

Equations: $S = A \oplus B \oplus C_{in}$, $C_{out} = AB + BC_{in} + AC_{in}$

3. Half Subtractor

Subtracts subtrahend bit $B$ from minuend bit $A$, producing Difference ($D$) and Borrow ($B_{or}$).

Equations: $D = A \oplus B$, $B_{or} = \overline{A} \cdot B$

Routes a single data input $D$ to one of four output channels ($Y_0-Y_3$) specified by select inputs $S_1, S_0$.

Unit 2: Sequential Logic Circuits

Sequential circuits incorporate memory elements (flip-flops/latches), allowing their state to depend on both current inputs and previous internal states.

1. SR Latch & D Latch

An SR Latch uses cross-coupled NOR/NAND gates. The state $S=1, R=1$ creates an undefined invalid condition. A D Latch resolves this state by passing input $D$ through an inverted path.

2. SR Flip-Flop & D Flip-Flop

Edge-triggered registers update output state ($Q$) on clock transitions (rising or falling edges). The schematic below details all pin connections including asynchronous Preset ($PRE$) and Clear ($CLR$) control data lines.

D Flip-Flop Truth Table:

Clock (CLK) D Input Q(t+1) Output Operation Mode
↑ (Rising Edge) 0 0 Reset State
↑ (Rising Edge) 1 1 Set State
0 / 1 / ↓ X Q(t) No Change (Hold State)
Figure 3.1: D-Flip-Flop Pin Schematic with Asynchronous Signals & High State Data Output

3. Shift Registers

Cascaded flip-flops configured to shift data linearly across clock pulses:

  • SISO (Serial-In Serial-Out): Delays data streams bit-by-bit.
  • SIPO (Serial-In Parallel-Out): Converts serial communication data to parallel bus words.
  • PISO (Parallel-In Serial-Out): Serializes parallel data registers.
  • PIPO (Parallel-In Parallel-Out): Serves as multi-bit storage registers.

Unit 3: Register Transfer & Micro-Operations

1. Register Transfer Language (RTL)

RTL provides standard notation to express hardware transfers between processor registers.

Example: $P: R2 \leftarrow R1$ specifies that if control signal $P = 1$, register $R1$ contents transfer into register $R2$.

2. Common Bus & Memory Transfers

Multiplexers or tri-state buffers interconnect internal registers over a shared bus.

3. Categorization of Micro-Operations

Category RTL Micro-operation Hardware Action
Arithmetic $R3 \leftarrow R1 + R2$ Adds contents of $R1$ and $R2$
Arithmetic $R1 \leftarrow R1 + 1$ Increments register $R1$
Logic $R1 \leftarrow R1 \oplus R2$ Bitwise XOR logic between $R1$ and $R2$
Shift $R1 \leftarrow \text{shl } R1$ Logical Shift Left (0 inserted in LSB)
Shift $R1 \leftarrow \text{ashr } R1$ Arithmetic Shift Right (preserves MSB sign bit)

Unit 4: Control Units & Instruction Execution

1. Execution of a Complete Instruction

Every instruction follows three core sequential phases:

  1. Fetch: $AR \leftarrow PC$; $IR \leftarrow M[AR]$, $PC \leftarrow PC + 1$
  2. Decode: Decode opcode in $IR$, evaluate addressing modes.
  3. Execute: Read operands, perform micro-operations, and store results.

2. Hardwired Control Unit Architecture

Hardwired Control Units use combinational logic gates, step counters, and instruction decoders to generate high-speed control signals ($C_i$). Below, a 16-bit Instruction Register ($IR$) field layout is decoded directly into timing signals ($T_0-T_7$) and gate control outputs.

Unit 5: Pipelining & Advanced Execution

1. Pipelining Fundamentals

Pipelining overlaps instruction execution phases (Fetch, Decode, Execute, Writeback) to improve overall instruction throughput.

2. Pipeline Hazards

  • Data Hazards: Occur when instructions depend on unwritten results of preceding instructions (RAW, WAR, WAW).
  • Instruction/Control Hazards: Caused by conditional branches altering the Program Counter ($PC$).
  • Structural Hazards: Occur when hardware resources are accessed simultaneously by multiple stages.

3. Superscalar Architecture

Superscalar CPUs incorporate multiple parallel execution pipelines to issue and execute multiple instructions per clock cycle (IPC > 1). The diagram below displays dual-issue pipeline execution with a 1-cycle data hazard stall.

2. Static RAM (SRAM) vs. Dynamic RAM (DRAM)

Feature Static RAM (SRAM) Dynamic RAM (DRAM)
Cell Structure 6-Transistor flip-flop circuit 1 Transistor + 1 Storage Capacitor
Periodic Refresh Not Required Required constantly
Access Speed Fast (< 10 ns) Slower (~50 ns)
Primary Role CPU Cache Memory Main System RAM

3. Cache & Virtual Memory

Cache Memory buffers active program data to reduce CPU memory latency. Virtual Memory expands physical address space onto secondary storage using paged address translations.
